# 📊 Super Store Sales Dashboard

An interactive **Power BI dashboard** built to analyze Super Store sales data and generate meaningful business insights through data visualization and interactive reporting.

The dashboard provides an overview of **sales performance, profit, orders, customers, products, and regional trends**, helping identify patterns and areas of business performance.

## 🎯 Project Objective

The objective of this project is to analyze Super Store sales data using **Microsoft Power BI** and create an interactive dashboard that helps users:

* Monitor overall sales performance
* Analyze profit and order trends
* Identify high-performing product categories
* Understand regional sales performance
* Compare sales across different segments
* Analyze customer and product-level performance
* Identify trends and patterns for better business decision-making

## 🔄 Data Preparation

The dataset was prepared for analysis using **Power Query**.

The general data preparation process includes:

1. Importing the Super Store dataset
2. Inspecting the available fields
3. Handling missing or inconsistent values
4. Formatting columns appropriately
5. Transforming data types
6. Creating required calculated fields
7. Loading the transformed data into Power BI
8. Building relationships and measures
9. Creating interactive visualizations
